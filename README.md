# InfoSec Audit Tools

![Security](https://img.shields.io/badge/Focus-Information%20Security-red.svg)
![Automation](https://img.shields.io/badge/Type-Automation-blue.svg)
![Bash](https://img.shields.io/badge/Language-Bash%20%7C%20Python-green.svg)

Репозиторий содержит набор скриптов и утилит для автоматизации аудита информационной безопасности, проверки конфигураций (Hardening) и сбора данных об инфраструктуре.

## Назначение

Инструменты предназначены для системных администраторов и специалистов по ИБ. Они позволяют автоматизировать рутинные проверки, проводить внутренний аудит защищенности и подготавливать инфраструктуру к комплаенс-проверкам.

## Структура репозитория

Инструменты разделены по категориям (папкам). Каждый инструмент автономен и имеет собственную документацию.
